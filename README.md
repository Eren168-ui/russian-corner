# Russian Corner

macOS 桌面俄语词汇与主动口语训练应用。

Russian Corner 面向“A2 已完成、正在冲 B1”的长期日常训练。核心层保持原有 360 个审核词条和 231 条长期场景表达；补充层新增 80 个 A2→B1 日常词条、60 条表达和 24 个开口挑战，合计可用 440 个词条与 291 条长期表达。俄语大学校园与课堂交流已加入优先选题队列。补充层只读取基础/普通俄语白名单来源，专业俄语、转录、conflict 副本和 AI 练习计划会被硬隔离。

每天的新表达最多 20% 来自补充层，新词最多加入 1 个补充词；已经到期的复习卡不受比例限制。句子中的俄语词均可点击，并按需展示重音、词形、体对、支配、搭配和本句用法。应用还提供可自由拖动或四角吸附的桌面卡、8 个全局快捷键、俄语朗读、间隔复习、本地提醒、每日反馈、学习诊断和最近 7 天学习报告。支持 macOS 14 及以上版本。

## 构建

```bash
./Scripts/build-app.sh
open "dist/Russian Corner.app"
```

打包脚本会执行 SwiftPM release 构建，在 `dist/` 中生成 ad-hoc 签名的 `.app`，并验证应用资源、`Info.plist` 与签名。脚本不联网、不安装到 `/Applications`。

开发验证：

```bash
swift test -Xswiftc -warnings-as-errors
```

完整的操作、8 个全局快捷键、隐藏方式、权限、数据位置、报告导出、卸载说明和硬件验收边界见 [Documentation/USAGE.md](Documentation/USAGE.md)。

## 数据与能力边界

- 原始 Obsidian 语料只读；应用只使用独立的、审核后派生词库。
- 核心层资源保持不变；补充层通过独立 manifest、来源哈希和失败关闭校验加载，任何一个补充资源异常时自动退回核心层。
- 4,479 条扫描候选默认均为 `draft`；只有本批 60 句、80 词条和 24 个开口挑战被标记为 `reviewed`。
- 核心学习进度与 7 天试用统计分别保存在本机的 `RussianCorner.store` 和 `RussianCornerTrial.store`。
- 两段口述活动只读取实时音量以估算开口时长和长停顿，不录音、不保存音频、不提供回放。
- 7 天报告是给学习者直接阅读的中文 Markdown；导出时由用户在系统保存面板中选择位置。
- 应用不调用 AI 服务，也不自动分析或评价发音。在线词典为可选增强：配置 Yandex Dictionary 密钥后，只有用户点击的词原形会发送给词典；句子、原始资料和学习记录不会上传。密钥保存在当前 Mac 的应用偏好设置中，不调用钥匙串。
- 删除 `.app` 不会自动删除本地学习数据。
