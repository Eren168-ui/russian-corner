# Language Corner 新用户使用手册

这份手册写给第一次使用 Language Corner 的人。你不需要先研究所有功能；先完成一张“看提示 → 主动回忆 → 揭晓 → 再说”的卡，就已经开始了。

## 1. Language Corner 是什么

Language Corner 是一款英语与俄语主动回忆练习工具。它把练习卡放在电脑桌面一角，让你在课间、通勤前后、宿舍或电脑工作间隙，用几分钟把“看得懂”练成“说得出”。

界面品牌叫 Language Corner。为保留既有安装、权限和学习进度，当前磁盘应用包仍显示 `Russian Corner.app`。打开 `Russian Corner.app` 后看到 Language Corner 界面。

当前只有 macOS 版完成，支持 macOS 14 及以上版本。手机打开即可使用、可安装到手机桌面的入口，以及 iPhone、Android 和 Windows，当前状态均为“即将上线”。

它不会替你进行自动陪聊，也不会自动判断口音、重音或发音是否准确。它的核心工作是让你主动回忆、诚实评分、按时复习，并保存自己的学习证据。

## 2. 为什么要用主动回忆

看见单词时认识，不等于需要时能主动说出来。很多“学了却说不出”的情况来自三件事：

- 答案看得太早，只产生熟悉感，没有真正检索；
- 单词与搭配、语气、词形和下一句彼此分开；
- 一次碰巧说对后没有换场景再说，熟练度没有迁移。

Language Corner 会先给意图或线索，让你在看答案前尝试提取。练习的关键不是多看一遍，而是让这条提取路径反复发生。

## 3. 现在怎么用

在 macOS 14+ 打开 `Russian Corner.app`。打开 `Russian Corner.app` 后看到 Language Corner 界面，可以从屏幕顶部的菜单栏进入，也会看到桌面悬浮练习卡。

第一次打开建议这样做：

1. 打开 `Russian Corner.app` 后看到 Language Corner 界面，再从菜单栏选择今天练英语还是俄语。
2. 在设置里选择“安静默读”或“开口练习”。公共空间可选安静默读，方便说话时再选开口练习。
3. 把每天卡数设在 5–10 张之间；第一次不必追求数量。
4. 完成第一张卡：先回忆，再显示答案。
5. 把悬浮卡拖到不挡工作的地方，或把它折叠成角落按钮。

## 4. 每张卡怎么练

### 第一步：只看提示

先看中文意图、场景或目标语线索。不要立刻显示答案。

### 第二步：给自己 3 秒

尽量完整说出整句。安静环境不方便开口时，可以默念或写下；重点是先从脑中取出，而不是先看再跟读。

### 第三步：揭晓并找差异

检查的不只是大意，还包括搭配、词形、语序、礼貌程度和常见用法。然后按真实情况判断：

- **3 秒内完整说出**：属于高熟练表现，但仍要做一次搭配、接下一句或槽位替换。
- **意思正确，但搭配或用法有问题**：属于部分成功；修正后把整句重说一次。
- **揭晓后才想起来**：说明这次没有主动取出，应按较低熟练度记录。
- **完全不会**：先理解，再遮住答案复述；它会更早回到复习中。

不能靠点 Easy 假装掌握。评分不是奖章，而是决定内容何时回来的一条诚实记录。

### 第四步：再输出一次

高分或部分成功后，至少做一项：

- 说一个常见搭配；
- 接下一句，让对话继续；
- 做槽位替换，把时间、人物、地点换成自己的信息。

## 5. 英语和俄语各练什么

### 俄语

俄语当前有 440 个词条、274 条长期表达、24 个开口挑战和 32 个主题。

练习重点包括重音、词形、动词体、支配关系、常见搭配和从中文意图主动说出俄语。熟练后会逐步减少中文中转，并用同主题表达做场景串练。

### 英语

英语当前有 400 个词条、200 条表达、20 个主题和 20 个微场景。

练习重点包括自然句块、礼貌程度、常见回应、听后跟读、遮住文本复述和槽位替换。微场景不只要求说出第一句，也练对方回应后如何继续。

这些是已审核并随应用打包的内容数量，不是学习效果承诺。

两种语言的共同原则相同：先主动回忆，再核对；把“认识”推进到“能在场景中使用”。

## 6. 怎么点击词义

真实 App 中，所有目标语词都可以点击。

揭晓答案后，点击句中任意英语或俄语词，会在当前卡片内看到它的核心义和本句用法。俄语还会按内容显示重音、原形、当前词形、动词体、支配关系和常见搭配；英语会帮助你把词放回句块、语气和场景中理解。

再次点击同一个词可收起，点击另一个词会直接切换。查词只是辅助层，句子仍然是练习主体。

本地词义优先。用户主动点击英语或俄语单词并使用在线补充时，只发送该词的原形（lemma），不发送整句、中文提示、原始资料或学习记录；在线结果仅作补充，未自动经过人工审核。

## 7. 英语微场景与表达收集

从菜单栏打开“今日英语场景”，会依次经过：

1. 先理解人物、地点和目的；
2. 从双语辅助过渡到只看英语；
3. 先听，再跟读；
4. 遮住参考表达后复述；
5. 替换时间、地点或人物；
6. 接出常见回应并交换角色。

遇到字幕、阅读笔记或粘贴文本中真正想说的句子时，可打开“收集英语表达”。选中具体句子，再补上中文意图、使用场景、说话人角色、语体和常见回应。

保存后的内容先留在本地候选区，不会直接进入每日练习。你确认内容无误并标记为可练后，它才会加入练习。

## 8. 悬浮卡、菜单、折叠与隐藏

- **悬浮卡**：可拖到桌面任意位置，也可在设置里吸附到左上、右上、左下或右下；还可调整字号和不透明度。
- **菜单栏**：用于显示或隐藏练习卡、切换语言与话题、进入今日英语场景、设置、学习记录、今日反馈、学习诊断和近 7 天报告。
- **折叠**：卡片收成 58 × 58 的角落按钮，仍留在桌面。点按钮或再次使用折叠快捷键即可展开。
- **隐藏**：卡片从桌面消失，但学习队列不会丢。再次从菜单栏执行“显示练习卡”即可恢复。

折叠与隐藏不是一回事：折叠适合保留一个小入口，隐藏适合暂时完全清空桌面。

## 9. 八个全局快捷键

这些快捷键在其他应用位于前台时也可用：

| 快捷键 | 操作 |
| --- | --- |
| `Control+Option+R` | 显示或隐藏练习卡 |
| `Control+Option+N` | 下一项 |
| `Control+Option+S` | 朗读当前内容 |
| `Control+Option+A` | 显示答案 |
| `Control+Option+1` | 评分 Again |
| `Control+Option+2` | 评分 Hard |
| `Control+Option+3` | 评分 Easy |
| `Control+Option+C` | 折叠或展开卡片 |

若某个组合已被系统或其他软件占用，菜单栏会提示部分快捷键被占用。先修改冲突软件的组合，再重新打开 Language Corner。

## 10. 复习、诊断、反馈与学习记录

- **复习**决定内容何时再次出现。“完全不会”通常更早回来，熟练内容逐步拉开间隔。
- **学习诊断**帮助区分认词、主动提取、听句、搭配和限时口述中的困难。口述由你按 1–5 分自评。
- **今日反馈**记录最卡的地方、真正脱口而出的一句，以及完成或提前结束的原因。可以跳过，也可当天重新打开修改。
- **学习记录**呈现已完成数量、练习时长、反应时间、积压和最近练习情况。

近 7 天报告是滚动的近 7 天阶段回顾，会汇总使用天数、完成量、有效练习时长、主动提取方向、反应时间、积压、朗读与详情使用、每日反馈和口述活动摘要。它不是试用期限，也不代表应用只能使用 7 天。

报告只在你从菜单栏主动导出、并在系统保存窗口确认后写入你选择的位置。

## 11. 权限与隐私

### 通知

通知只用于上午和下午的本地提醒。拒绝通知权限后，词句练习、进度、反馈和诊断仍可使用。

### 麦克风

麦克风只在诊断的口述活动中用于估算开口时长和明显停顿。应用不创建录音文件，也不自动判断重音、口音或发音准确度。拒绝后会改为计时加自评，不影响日常练习。

### 本地记录

卡片评分、学习进度、诊断历史、反馈和设置保存在当前 Mac。删除应用本身不会自动删除这些记录。应用不宣称已经完成跨设备能力。

### 内容审核

正式练习使用审核后的英语和俄语内容。新收集的表达先隔离为候选，不会未经确认就进入训练。

### 无网与系统声音

无网时，本地学习仍可用，在线词典不可用。没有目标语系统声音时，文字训练照常，朗读和听力练习会降级。

### 原始笔记

原始 Obsidian 笔记保持只读，不会改动。

### 在线补充

用户主动点击英语或俄语单词并使用在线补充时，只发送该词的原形（lemma），不发送整句、中文提示、原始资料或学习记录；在线结果仅作补充，未自动经过人工审核。

## 12. 什么时候用最合适

- **课间 3 分钟**：安静完成三张卡。
- **通勤 5 分钟**：优先复习已经到期的表达。
- **宿舍 10 分钟**：开口、复述、换槽位并练微场景。
- **电脑前 30 秒**：工作告一段落后，从悬浮卡取一句。

最小单位不是“学完一课”，而是诚实地完成一张卡。

## 13. 常见问题

### 我必须每天完成很多卡吗？

不必。设置范围是每天 5–10 张，但第一次只要完整走完一张卡的闭环即可。质量比快速翻完更重要。

### 安静默读还有用吗？

有。它仍要求你在脑中主动提取并记录反应结果。方便开口时，再用开口练习把默念变成真实输出。

### 为什么我说对了还要继续练？

一次说对可能只是碰巧熟悉。做一次搭配、接下一句或槽位替换，才能确认表达可以迁移到新场景。

### 应用会自动给我的发音打分吗？

不会。诊断中的口述活动只估算是否开口和明显停顿，准确度、口音和重音仍需要你自己、老师或母语者判断。

### 拒绝麦克风或通知权限还能用吗？

可以。拒绝麦克风后，口述活动改为计时加自评；拒绝通知后不再提醒。日常练习、记录和诊断不会因此被阻塞。

### 折叠后卡片去哪了？

它会变成桌面角落的 58 × 58 按钮。若完全看不到，可能是被隐藏了，请从菜单栏选择“显示练习卡”或按 `Control+Option+R`。

### 近 7 天报告是不是到期提示？

不是。它是不断向前滚动的阶段观察窗，不代表使用期限。

### 手机和 Windows 现在能用吗？

当前只有 macOS 14+ 版完成。手机打开即可使用、可安装到手机桌面的入口，以及 iPhone、Android 与 Windows，当前状态都是“即将上线”。
