# Russian Corner 使用指南

Russian Corner 是一款 macOS 14 及以上版本的本地菜单栏俄语练习应用。它从审核后的派生词库安排词汇和句子练习，并把进度保存在本机。

## 构建与打开

在仓库根目录运行：

```bash
./Scripts/build-app.sh
open "dist/Russian Corner.app"
```

脚本会执行 release 构建，生成 `dist/Russian Corner.app`，检查资源、`Info.plist` 和 ad-hoc 签名。脚本不会联网，也不会把应用安装到 `/Applications`。若要长期使用，可在 Finder 中自行把 `.app` 复制到 `/Applications`；复制后首次打开若被系统拦截，请在“系统设置 → 隐私与安全性”中确认来源并允许打开。

应用是菜单栏程序，不显示 Dock 图标。启动后，菜单栏会出现书本图标，练习卡默认显示在屏幕右上角。

## 菜单栏与角落练习卡

菜单栏可显示或隐藏练习卡、切换到下一项、把卡片移到下一块显示器，并打开设置、学习进度和学习诊断窗口。

练习卡的基本流程：

1. 先看中文提示或俄语线索，尽量主动回忆。
2. 点“显示答案”核对俄语内容。词汇卡会同时显示重音、词性、必要词法信息、1–2 个搭配、例句和关联场景。
3. 揭晓后按实际感受选择 `Again`、`Hard` 或 `Easy`。
4. 用“下一项”跳过当前项不会记录评分。

卡片支持朗读、录音、播放、保存、丢弃、收起和展开。未明确保存的临时录音会在切换练习项或退出时清理；已保存的录音留在本地。

## 9 个全局快捷键

这些快捷键在其他应用处于前台时也可使用：

| 快捷键 | 操作 |
| --- | --- |
| `Control+Option+R` | 显示或隐藏练习卡 |
| `Control+Option+N` | 下一项 |
| `Control+Option+S` | 朗读当前内容 |
| `Control+Option+A` | 揭晓答案 |
| `Control+Option+1` | 评分 `Again` |
| `Control+Option+2` | 评分 `Hard` |
| `Control+Option+3` | 评分 `Easy` |
| `Control+Option+M` | 开始或停止录音 |
| `Control+Option+C` | 收起或展开卡片 |

若快捷键已被 macOS 或其他软件占用，菜单栏会显示“部分全局快捷键被占用”。请先修改冲突软件的快捷键。

## 安静默读与开口练习

在“设置 → 练习”中选择：

- “安静默读”：适合公共空间，不要求主动开口。
- “开口练习”：用于朗读、复述和录音自查。

两种方式都会记录卡片评分和反应时间。切换练习方式不会让应用自动评价发音。

## 词句练习与学习诊断

日常队列由审核后的 360 个词汇记录和 72 个句子卡组成。每天的新词基准是 10 个：前一天主动回忆正确率低于 75% 或待复习词达到 20 个时降为 6 个；连续三天高于 90% 且无明显积压时升为 12 个。每周日只安排已学词复习；首次使用若尚无已学内容，会提供 6 个新词，避免出现空白卡片。

句子卡数量使用“设置”里的每日 5–10 张。词汇和句子会使用当天日期形成稳定队列，因此同一天重启顺序不漂移，隔天会更换抽取顺序。`Again` 会把当前项排到本次队列稍后重练，同时把间隔复习日期设为次日；`Hard` 和 `Easy` 成功提交后，当天重启不会再次投放同一项。队列练完后会显示完成状态，不会从头无限循环。

低熟练卡使用中文意图或场景提示；句子卡达到熟练度 3 后，在俄语线索与答案不相同的前提下改用俄语线索，逐步减少中文中转。

最新一份有效诊断也会参与排程：出现“词汇广度”或“主动提取”问题时，每日新词上限收紧为 6；出现“听力差距”或“自我监控”问题时，尚未手动选择练习方式的用户会默认进入开口练习。你在设置中明确选择的“安静默读/开口练习”始终优先，不会被诊断覆盖。

“学习诊断”包含认词、中文到俄语、10 条听句、搭配自评，以及两段最多 60 秒的表达录音。麦克风步骤可以跳过，不会阻塞诊断。报告展示基线或周复测指标和基于证据的训练提示。

诊断不会分析录音内容，也不会自动判断发音准确度或母语地道度；这些仍需老师或母语者评估。

## 设置与提醒

设置窗口可调整：

- 练习卡所在显示器、四角吸附位置、不透明度和字号；
- 每日 5–10 张卡及安静/开口方式；
- 上午、下午两次本地提醒，默认时间为 11:30 和 17:30。

修改每日卡数后点“应用每日卡数”。修改提醒后点“保存并更新提醒”。

## 首次权限

- 麦克风：第一次开始录音时，macOS 会请求权限。拒绝后仍可继续学习和跳过录音；可到“系统设置 → 隐私与安全性 → 麦克风”重新开启。
- 通知：第一次保存提醒设置时，macOS 会请求通知权限。拒绝不会删除学习进度，但系统不会展示提醒；可到“系统设置 → 通知 → Russian Corner”重新开启。

## 本地数据与隐私边界

应用不调用 AI 服务，不上传内容，也不自动进行发音评分。原始 Obsidian 资料保持只读；运行时只读取随应用打包的、审核后的派生 JSON 词库。

本地数据位置：

- 卡片显示、练习方式等偏好：`~/Library/Preferences/com.openclaw.russiancorner.plist`
- 学习进度、评分、提醒设置和诊断历史：`~/Library/Application Support/default.store` 及同目录的 `default.store-*` 辅助文件（由 SwiftData 管理）
- 手动保存的录音：`~/Library/Application Support/RussianCorner/Recordings/`
- 未保存的录音：系统临时目录，切换练习项或退出时清理

## 卸载

退出 Russian Corner 后，删除你放置的 `Russian Corner.app` 即可卸载。删除 `.app` 不会自动删除上述学习数据、偏好或已保存录音；需要保留历史时请先备份这些位置。本文只说明数据位置，不自动执行数据删除。

## 当前验收边界

自动验收覆盖编译、单元测试、资源数量和解析路径、bundle identifier、`Info.plist`、签名及进程启动。以下行为仍需要在目标 Mac 和真实硬件上人工确认：

- 麦克风授权、录制、播放与实际音质；
- 通知授权后两次提醒的实际送达；
- 系统是否安装可用的 `ru-RU` 语音及朗读效果；
- 9 个全局快捷键是否与本机软件冲突；
- 多显示器移动、四角吸附和不同缩放比例下的视觉效果。
