# Russian Corner 使用指南

Russian Corner 是一款 macOS 14 及以上版本的本地菜单栏俄语练习应用。它从审核后的派生词库安排词汇和句子练习，并把进度保存在本机。

## 构建与打开

在仓库根目录运行：

```bash
./Scripts/build-app.sh
open "dist/Russian Corner.app"
```

脚本会执行 release 构建，生成 `dist/Russian Corner.app`，检查资源、`Info.plist` 和 ad-hoc 签名。脚本不会联网，也不会把应用安装到 `/Applications`。若要长期使用，可在 Finder 中自行把 `.app` 复制到 `/Applications`；复制后首次打开若被系统拦截，请在“系统设置 → 隐私与安全性”中确认来源并允许打开。

应用会显示正常的 Dock 运行状态，同时在菜单栏提供常用入口。启动后练习卡默认显示在屏幕右上角；可以把卡片拖到桌面任意位置并保持自由位置，也可以在设置中主动选择左上、右上、左下或右下吸附位置。

## 菜单栏与角落练习卡

菜单栏可显示或隐藏练习卡、切换到下一项、把卡片移到下一块显示器，并打开设置、学习进度、今日反馈和学习诊断窗口，也可导出最近 7 天的试用报告。

默认卡片为 360×240，只保留“提示 → 主动说出 → 显示答案 → Again/Hard/Easy”的主路径。答案区最多先显示一条常用搭配；点“详情”后原位展开为 430×386，再查看词法、支配关系、其他搭配、例句和微型对话。卡片会跟随 macOS 深色/浅色外观自动切换，不需要单独设置主题。

隐藏与收起不是一回事：

- 菜单栏点“隐藏练习卡”，或按 `Control+Option+R`，卡片会从桌面消失；再次执行同一操作即可恢复，学习队列不会丢失。
- 按 `Control+Option+C` 或点卡片右上角减号，卡片会收成 58×58 的角落按钮；点按钮或再次按快捷键即可展开。

练习卡的基本流程：

1. 上午词卡默认从俄语认中文，下午默认从中文主动说俄语；词卡上的“俄→中 / 中→俄”按钮可随时切换方向。应用长时间常驻时会自动检查中午和午夜边界，跨中午切换默认方向，跨天刷新当天队列。
2. 点“显示答案”核对俄语内容。句子中的每个俄语词都带轻量下划线并可点击；点击任意词，卡片原位展开该词的重音、中文义、原形、当前词形、词性、体对、支配、搭配和本句用法。再次点击同一词关闭，点击另一词直接切换。正文始终是主角，解析只按需展开。
3. 揭晓后按实际感受选择 `Again`、`Hard` 或 `Easy`。
4. 用“下一项”跳过当前项不会记录评分。

卡片支持朗读、收起、展开详情和一键隐藏。日常卡片没有录音、播放或保存入口，也没有录音快捷键。

## 8 个全局快捷键

这些快捷键在其他应用处于前台时也可使用：

| 快捷键 | 操作 |
| --- | --- |
| `Control+Option+R` | 显示或隐藏练习卡 |
| `Control+Option+N` | 下一项 |
| `Control+Option+S` | 朗读当前内容 |
| `Control+Option+A` | 揭晓答案 |
| `Control+Option+1` | 评分 `Again` |
| `Control+Option+2` | 评分 `Hard` |
| `Control+Option+3` | 评分 `Easy` |
| `Control+Option+C` | 收起或展开卡片 |

若快捷键已被 macOS 或其他软件占用，菜单栏会显示“部分全局快捷键被占用”。请先修改冲突软件的快捷键。

## 安静默读与开口练习

在“设置 → 练习”中选择：

- “安静默读”：适合公共空间，不要求主动开口。
- “开口练习”：用于朗读和复述。

两种方式都会记录卡片评分和反应时间。切换练习方式不会让应用自动评价发音。

## 长期词句练习与学习诊断

应用当前提供 440 个可用词条和 274 条长期表达：核心层为原有 360 词条、214 表达；补充层新增 80 个 A2→B1 日常词条和 60 条日常表达，另保留 24 个 B1 开口挑战。每天的新词基准是 10 个：前一天主动回忆正确率低于 75% 或待复习词达到 20 个时降为 6 个；连续三天高于 90% 且无明显积压时升为 12 个。每周日只安排多条已学词和已学句复习，不加入新内容；复习词量使用当天自适应目标，首次使用若尚无已学内容则提供 6 个新词，避免出现空白卡片。

默认学习者档位是“A2 已完成、正在冲 B1”。`привет`、`здравствуйте`、`спасибо`、`понимать`、`знать` 以及最基础的家庭、住房、饮食和时间词不会作为独立新词卡占用名额；它们仍可自然出现在例句或对话中。经过该筛选后仍保留至少 250 个审核词条，重点投放高频动词、体对、支配关系、固定搭配、连接表达和真实场景词汇。学习诊断使用同一档位，不再用问候语等入门词测试词汇量。

补充层只允许来自三个基础/普通俄语目录，并保留 `sourcePath`、原文和 SHA-256。扫描得到的 4,479 条候选默认全部是 `draft`；当前只投放人工回读过的 60 句、80 词条，专业俄语、课堂转录、conflict、双链报告和 AI 计划不会进入队列。任何补充资源缺失、来源不一致或字段不完整时，应用会自动退回原核心层。

为了让核心场景继续占主导，每天“今日新内容”中的补充表达最多占 20%，补充新词最多 1 个；同日重练、昨日未完成和已经到期的补充卡不受这个上限限制，不会漏掉该复习的内容。

句子卡数量使用“设置”里的每日 5–10 张。词汇和句子会使用当天日期形成稳定队列，因此同一天重启顺序不漂移，隔天会更换抽取顺序。`Again` 会把当前项排到本次队列稍后重练，同时把间隔复习日期设为次日；`Hard` 和 `Easy` 成功提交后，当天重启不会再次投放同一项。队列练完后会显示完成状态，不会从头无限循环。

低熟练卡使用中文意图或场景提示；句子卡达到熟练度 3 后，在俄语线索与答案不相同的前提下改用俄语线索，逐步减少中文中转。

同一主题的句子会在揭晓后组成 2–3 轮“场景串练”，用于跟读、遮住答案复述和完成当天的微型对话。基础词不会因此变成独立新词卡；句内点击是理解表达的辅助层，不占每日新词名额。

最新一份有效诊断也会参与排程：出现“词汇广度”或“主动提取”问题时，每日新词上限收紧为 6；出现“听力差距”或“自我监控”问题时，尚未手动选择练习方式的用户会默认进入开口练习。你在设置中明确选择的“安静默读/开口练习”始终优先，不会被诊断覆盖。

“学习诊断”包含认词、中文到俄语、10 条听句、搭配自评，以及“60 秒自我介绍”和“60 秒日常生活口述”。每段先准备 3 秒，再计时 60 秒，最后由你按 1–5 分评价流畅度。

麦克风可用时，应用只读取实时音量活动，给出大致开口秒数和明显长停顿次数；它不会创建音频文件。麦克风权限被拒绝或设备不可用时，流程自动退化为计时 + 自评，诊断仍可完成。

这些数字只是活动估算，不是语音识别，也不能判断重音、口音、发音准确度或母语地道度；这些仍需老师或母语者评估。

## 今日反馈与最近 7 天报告

完成当天最后一张卡后，角落卡会轻量询问一次：今天最卡的地方、是否有一句真正脱口而出，以及完成或提前退出的原因。可以直接跳过；跳过后当天不会再次自动打扰。菜单栏“今日反馈…”可随时重新打开、保存或修改，同一天多次保存只更新一条记录。

菜单栏“导出 7 天学习报告…”会生成正常可读的中文 Markdown，汇总滚动最近 7 天的使用天数、完成量、有效练习时长、三种主动提取方向、反应时间、积压、详情/朗读使用、每日反馈和口述活动摘要。它只是长期使用中的阶段报告，不代表应用只能使用 7 天。报告明确区分客观记录和用户自述，不自动替你生成下一轮学习结论。

报告只在你确认 macOS 系统保存面板后写入，文件名默认为 `俄语角落卡-7天试用报告-YYYY-MM-DD.md`，保存位置由你选择；应用不会自动写入 OneDrive 或 Obsidian，也不会导出 JSON、音频或原始资料路径。

## 设置与提醒

设置窗口可调整：

- 练习卡所在显示器、四角吸附位置、不透明度和字号；
- Yandex Dictionary 在线补充密钥（可选，存入当前 Mac 的应用偏好设置，不调用钥匙串）；
- 每日 5–10 张卡及安静/开口方式；
- 上午、下午两次本地提醒，默认时间为 11:30 和 17:30。

修改每日卡数后点“应用每日卡数”。修改提醒后点“保存并更新提醒”。

应用首次启动时会请求通知权限；授权后立即建立默认的两次提醒。以后每次启动都会对照本地数据库中的提醒时间检查两个固定通知，若通知缺失或时间不一致会自动修复。拒绝权限或当前系统不支持通知只会关闭提醒，不会影响词汇、句子、进度和诊断功能。

## 首次权限

- 麦克风：第一次开始口述活动检测时，macOS 会请求权限。拒绝后自动使用计时 + 自评，不影响日常学习和诊断；可到“系统设置 → 隐私与安全性 → 麦克风”重新开启。
- 通知：第一次启动时，macOS 会请求通知权限。拒绝不会删除学习进度，也不会阻塞应用启动；可到“系统设置 → 通知 → Russian Corner”重新开启，之后重启应用即可自动补齐两次提醒。

## 本地数据与隐私边界

应用不调用 AI 服务，也不自动进行发音评分。原始 Obsidian 资料保持只读；运行时只读取随应用打包的、审核后的派生 JSON 词库。

句内词义始终先使用本地审核数据。若在设置中配置 Yandex Dictionary 密钥，点击句中单词时应用会把该词的俄语原形发送至 Yandex Dictionary，补充中译、近义词和例句；不会发送整句、中文提示、原始资料路径、评分或学习记录。网络失败、词典无结果或移除密钥时，本地解析照常工作。在线结果只在当前运行期间作内存缓存，不写入学习数据库。详情中的“词典”链接可按需打开俄语 Wiktionary。

本地数据位置：

- 卡片显示、练习方式等偏好：`~/Library/Preferences/com.openclaw.russiancorner.plist`
- 学习进度、评分、提醒设置和诊断历史：`~/Library/Application Support/com.openclaw.russiancorner/RussianCorner.store` 及同目录的 `RussianCorner.store-*` 辅助文件（由 SwiftData 管理）
- 试用会话、交互、每日反馈和口述活动数字摘要：同目录的 `RussianCornerTrial.store` 及 `RussianCornerTrial.store-*` 辅助文件
- Yandex Dictionary API 密钥（若配置）：当前用户的应用偏好设置键 `RussianCorner.YandexDictionaryAPIKey`

两个数据库彼此独立。试用统计库损坏或不可写时，评分、复习进度和当天队列仍继续使用核心数据库；应用只显示非阻塞提示。口述活动摘要只含时长、估算开口秒数、估算长停顿次数和自评分，不含音频数据或文件路径。

首版不会读取、迁移或删除 `~/Library/Application Support/default.store`。这个通用文件名可能属于其他 SwiftData 程序，因此 Russian Corner 只使用自己的专属目录；如你曾运行过内部开发版，旧 `default.store` 会原样保留，不会被本应用盲目接管。

## 卸载

退出 Russian Corner 后，删除你放置的 `Russian Corner.app` 即可卸载。删除 `.app` 不会自动删除上述两个数据库或偏好；需要保留历史时请先备份这些位置。本文只说明数据位置，不自动执行数据删除。

## 当前验收边界

自动验收覆盖编译、单元测试、资源数量和解析路径、bundle identifier、`Info.plist`、签名及进程启动。以下行为仍需要在目标 Mac 和真实硬件上人工确认：

- 麦克风授权、实时活动估算和不同背景噪声下的估算表现；应用不录音、无音质或回放验收项；
- 通知授权后两次提醒的实际送达；
- 系统是否安装可用的 `ru-RU` 语音及朗读效果；
- 8 个全局快捷键是否与本机软件冲突；
- 多显示器移动、四角吸附和不同缩放比例下的视觉效果。
