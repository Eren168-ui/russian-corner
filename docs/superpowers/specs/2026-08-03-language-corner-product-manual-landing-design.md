## 2. 产品最终形态

Language Corner 定义为一套跨设备的英语与俄语主动口语学习系统，而不是只面向 Mac 的悬浮卡工具。

### 2.1 当前已经可用

- macOS 原生菜单栏应用。
- 英语与俄语可在同一应用内切换，内容和进度彼此隔离。
- 桌面练习卡可自由拖动、可选四角吸附、折叠、隐藏、置顶、调节透明度与字号。
- 支持主动回忆、句中词点击解析、朗读、间隔复习、学习记录、每日反馈、学习诊断与最近 7 天报告。
- 核心学习本地运行；在线词典只作为用户主动查询时的可选补充。

兼容性说明必须写清楚：应用界面品牌是 `Language Corner`，为了保留既有安装、权限与学习数据，当前应用包仍显示为 `Russian Corner.app`。

### 2.2 规划中的产品入口

- 手机 Web/PWA：面向 iPhone、Android 和普通浏览器，作为大学生日常碎片化训练的主要入口。
- iOS/Android App：在移动 Web 流程验证后，用同一套前端和内容能力封装正式移动客户端，并补充原生通知、小组件和系统分享入口。
- Windows：第一阶段使用可安装 PWA；确认桌面悬浮需求后，再增加托盘、置顶悬浮、全局快捷键和开机启动等原生能力。
- 可选账号与同步：允许匿名、本地使用；只在用户需要跨设备接续时才要求登录。

落地页只能把这些内容标记为“产品方向”“下一阶段”或“规划中”，不得出现虚假的下载按钮、发布日期或已上线表述。

## 3. 目标用户与用户问题

### 3.1 核心用户

- 学过基础语法但开口反应慢的大学生。
- 俄语处于 A2 以上、B1 以下，认识一部分词，但主动词汇和搭配不足。
- 英语有持续输入习惯，例如无字幕影视和纯英文阅读，但表达仍不够自动化。
- 无法每天拿出完整课时，希望利用课间、通勤、排队、工作间隙和睡前时间练习。

### 3.2 需要解释清楚的问题

落地页必须用普通用户语言回答：

1. 这是什么产品？
2. 它和背单词 App、录音机或普通题库有什么不同？
3. 为什么“看得懂”不等于“说得出”？
4. 第一次打开该做什么？
5. 一张卡怎样才算真正练完？
6. 点击单词后能得到什么？
7. `Again / Hard / Easy` 或新的回忆结果分别意味着什么？
8. 学习诊断、每日反馈和报告有什么实际用途？
9. 在电脑、手机规划版和不同场景下应该怎样使用？
10. 哪些功能需要网络、通知或麦克风权限？

## 4. 学习逻辑

页面主叙事使用以下学习闭环：

`场景意图 → 3 秒主动说出 → 揭晓自然表达 → 点击不懂的词 → 完成迁移任务 → 根据证据安排复习`

重点解释：

- 句子始终是主角，单词解析按需展开。
- 学习单位不是孤立单词，而是单词、固定搭配、句块、场景句和下一轮回应。
- 揭晓答案不等于学会。用户还要完成搭配、下一轮回应或替换姓名、地点、时间、数量等迁移任务。
- 评分同时参考反应时间和迁移任务结果，避免“随手点 Easy 就算掌握”。
- 英语强调听力反应、影剧输入转化、复述和回应；俄语强调 A2→B1 词汇、词形、支配、搭配和日常场景表达。

揭晓后的四档结果使用当前产品的真实含义：

1. 3 秒内完整说出。
2. 核心意思正确，但搭配或用法有问题。
3. 揭晓后才想起来。
4. 完全不会。

高分或部分成功后仍需完成搭配、下一轮回应或槽位替换任务；最高熟练度不能只靠一次点击产生。

## 5. 新用户使用路径

### 5.1 当前 macOS 路径

1. 打开应用，在菜单栏或 Dock 确认 Language Corner 正在运行。
2. 选择英语或俄语。
3. 在设置中选择每日卡数、安静默读或开口练习，以及提醒时间。
4. 将卡片拖到桌面任意位置；需要时折叠为小图标或完全隐藏。
5. 看到提示后先说，不先读答案。
6. 揭晓后点击不认识的目标语单词，查看词义、原形/当前词形、语法、搭配、例句和来源。
7. 完成迁移任务，再提交真实回忆结果。
8. 练完后可查看学习记录；诊断和每日反馈是可选的辅助入口，不阻塞日常练习。

### 5.2 未来手机路径

1. 扫二维码或打开链接，不注册即可体验三张卡。
2. 选择语言、水平和每天愿意投入的时间。
3. 第一次练习完成后，再提示添加到主屏幕和开启通知。
4. 日常通过通知、小组件或首页的“继续今天”进入 3、5 或 10 句短练习。
5. 根据环境选择安静模式、耳机模式或开口模式。
6. 第三天后再邀请用户完成学习诊断；不在首次进入时设置长问卷或强制麦克风授权。

## 6. 页面信息架构

新版由 14 个可独立导出的章节构成：

1. **首屏：这不是背单词 App**  
   定义双语 Language Corner，标识 `macOS 当前可用 / 手机与 Windows 路线图`。

2. **为什么会卡住**  
   解释阅读词汇与主动词汇、孤立单词与句块、文字听力差距、中文中转与过度语法检查。

3. **它现在是什么产品、在哪些平台可用**  
   说明当前是 macOS 14+ 原生应用，手机 Web/PWA、iOS、Android 和 Windows 均属于明确路线图。

4. **产品怎样解决问题**  
   用一张清晰流程图展示完整主动提取闭环。

5. **第一次打开：两分钟开始**  
   使用真实产品界面逻辑，说明语言切换、设置、卡片位置和第一张卡。

6. **一张卡怎样练**  
   提示、开口、揭晓、迁移和评分分步呈现。

7. **点击句中任何单词**  
   提供可操作演示，展示本地审核释义和可选在线词典补充。

8. **英语与俄语分别练什么**  
   双栏展示两条学习路径，明确不做英俄互译卡；俄语侧展示词形、体对、支配、固定搭配、下一轮回应和角色语用。

9. **英语微场景与输入转化**  
   展示双语理解、英语独白、音频优先、跟读、复述、变式和对话；说明字幕或笔记表达先进入候选区，审核后才进每日队列。

10. **悬浮卡、菜单栏与系统功能**  
    解释自由拖动、可选四角吸附、折叠与隐藏的区别、Dock 状态、菜单栏、卡片内更多入口、快捷键和通知权限入口。

11. **每天怎么用最有效**  
    展示课间 30 秒、通勤 5 分钟、上午 10 分钟、晚间 10–15 分钟和电脑工作间隙等真实场景。

12. **复习、诊断、记录与每日反馈**  
    用“它回答什么问题”解释各入口，区分客观记录、系统评分和用户自述；解释最近 7 天报告是滚动阶段回顾，不是试用期限。

13. **权限、网络与隐私**  
    解释通知、麦克风、TTS、在线词典、本地数据、原始笔记只读和离线降级。

14. **首次五分钟清单、跨端路线与收束**  
    提供可照着做的行动清单，解释当前 Mac、未来手机主入口和 Windows 桌面伴侣的角色，不使用虚假下载链接。

## 7. 视觉设计

保留旧页面的编辑式长图气质，但升级为“现代语言学习档案 / 实用产品手册”，不做传统 SaaS 模板。

### 7.1 视觉系统

- 基础色：暖纸白、深海军蓝、炭黑。
- 俄语识别色：克制的钴蓝。
- 英语识别色：砖红或暖橙。
- 功能状态色只用于当前可用、规划中、可选增强等明确状态。
- 中文标题使用宋体气质字体栈，正文使用系统无衬线；英语与俄语例句使用可读性好的衬线字体。
- 保留编号、网格、编辑批注和学习卡片重建；减少旧版大面积空白，提高信息密度。

### 7.2 版式

- 桌面宽度以 1440px 导出为基准。
- 浏览版提供固定页内目录和阅读进度。
- 移动端采用单列，按钮和可点击词满足触控尺寸。
- 章节边界清晰，每一章都能独立导出为海报，同时连续阅读不割裂。
- 产品卡片用 HTML/CSS 忠实重建，必要时使用应用自带图标；不使用包含私人桌面内容的截图。
- 使用真实应用图标时，将 `/Users/Openclawworkspace/workspace/russian-corner/Assets/AppIcon/RussianCorner-source.png` 复制到落地页自身的 `assets/`，不保留跨项目绝对路径依赖。

### 7.3 动效

- 浏览模式只使用轻量淡入、状态切换和词条展开。
- 遵循 `prefers-reduced-motion`。
- `?export=1` 下关闭全部动效并展示最终状态。
- 不使用导致窗口或页面剧烈跳动的等比例缩放。

## 8. 交互组件

1. 页内目录与章节跳转。
2. 英语/俄语学习路径切换，不隐藏另一门语言的产品定位。
3. 可点击句中词演示，至少支持一个英语词和一个俄语词。
4. 当前平台/规划平台状态卡。
5. 新手五分钟清单，可在浏览器中勾选但不上传。
6. 浏览版与导出静态版两种状态。

页面无需账号、后端或分析脚本。所有演示数据必须是静态、匿名和可追溯的产品示例。

## 9. 内容真实性与边界

- 俄语当前资源可写为 440 个可用词条、274 条长期表达、24 个开口挑战和 32 个主题；同时说明数量不是学习效果承诺。
- 英语当前资源可写为 400 个审核词条、200 条场景表达、20 个主题和 20 个微场景。
- “全部目标语单词可点击”仅指界面覆盖能力，不表示每个在线词典结果都经过人工审核。
- 不宣传 AI 自由对话、自动发音评分、云同步、手机 App 或 Windows 原生悬浮窗已经完成。
- 不展示真实 API 密钥、原始资料绝对路径、用户桌面、私人学习记录或伪造用户评价。
- 报告应解释为“最近 7 天的阶段回顾”，不得再写成产品只能试用 7 天。
- 主题名称从实际资源中选择，不沿用未经核实的示意编号。
- 用户导入的影视字幕只能描述为“用户可自行收集的表达来源”，不得写成产品内置影视语料。

## 10. 异常与降级说明

- 没有网络：本地词句、复习和学习记录仍可使用；在线词典不可用。
- 通知权限被拒绝：用户仍能主动打开练习；页面给出系统设置入口说明。
- 没有目标语言系统声音：文字训练仍可用，朗读与听力功能降级。
- 麦克风权限被拒绝：日常卡片不受影响；口述活动退化为计时，不伪装成发音评分。
- 快捷键冲突：菜单栏和卡片内的更多菜单仍能完成同样操作。

## 11. 使用手册文件结构

独立手册采用以下顺序：

1. 一句话认识 Language Corner。
2. 适合谁、不适合谁。
3. 五分钟开始使用。
4. 每张卡的正确练法。
5. 英语与俄语的差异化训练。
6. 单词详情、迁移任务与复习评分。
7. 卡片移动、折叠、隐藏、快捷键和提醒。
8. 诊断、反馈、学习记录与报告。
9. 权限、网络、隐私和数据位置。
10. 常见问题与故障排查。
11. 当前平台和跨平台路线图。

手册面向用户，不出现内部模式名称、测试类名、架构术语或开发验收话术。

### 12.3 用户结果验收

随机请一名不了解项目的人只阅读页面后，应能准确说出：

1. 产品当前是 macOS 双语主动口语学习应用。

3. 正确练法是先主动说，再揭晓、查词、迁移和复习。
4. 日常学习不要求长时间坐在电脑前，未来手机入口服务于碎片化使用。
