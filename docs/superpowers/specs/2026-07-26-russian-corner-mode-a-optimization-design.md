# Russian Corner MODE A 上线前优化设计

日期：2026-07-26  
状态：已获方向批准，等待用户审阅书面规格  
范围：视觉精修、碎片交互、7 天试用数据闭环、口述检测用途收敛

## 1. 背景与决策

Russian Corner 第一版已经具备菜单栏应用、四角悬浮卡、词句联动、
自适应复习、朗读、录音、提醒、诊断和本地进度系统。用户尚未完成
7 天真实试用，因此本轮进入 MODE A：只完成上线前优化和试用准备，
不依据想象实施大规模学习机制重构。

本轮已确认：

- 角落卡以 10–20 秒碎片主动提取为核心。
- 借鉴 AIM Read 的视觉语言，但保留 macOS 原生交互。
- 保留 `Again / Hard / Easy` 及其现有复习语义。
- 默认揭晓层只显示答案、一个高频搭配和朗读入口。
- 详细语法、例句和场景按需展开。
- 浅色和深色同时精修，跟随 macOS。
- 应用自动记录客观试用数据，每天完成后提供三个可跳过的主观问题。
- 7 天报告只导出面向用户的中文 Markdown，不导出 JSON。
- 日常角落卡移除通用录音机式操作。
- 麦克风只用于有明确指标输出的周期口述检测；不保存音频，不宣称
  发音评分。

## 2. 目标与非目标

### 2.1 目标

1. 默认卡片不遮挡工作，单次训练能在 10–20 秒内完成。
2. 提示、答案、评分和下一项形成清楚、低摩擦的主路径。
3. 详细语言信息仍然可达，但不占据默认卡面。
4. 7 天后能用真实完成率、耗时、反应时间、积压和退出点判断下一轮
   应优化什么。
5. 口述功能必须产生用户无需回听音频也能理解的客观估算结果。
6. 升级不得破坏现有学习进度、词库关联、提醒和权限降级路径。

### 2.2 非目标

本轮不加入：

- AI 场景对话或自动发音评分；
- 账号、云同步、远程遥测；
- 英语学习模块；
- 游戏化、排行榜或社交；
- 完整六触点训练中心；
- 图片提示、全量词族系统或全量词形操练；
- 大规模架构重构；
- 未经 7 天数据支持的卡量和调度变化。

## 3. 方案比较

### 方案 A：只做视觉换肤

仅调整颜色、字体、阴影和圆角。成本最低，但无法解决默认卡面信息
过载，也不能形成 7 天试用证据。

### 方案 B：紧凑卡片、视觉精修和试用闭环

缩短默认操作路径，详细内容按需展开，同时补充独立的本地试用记录
和 Markdown 报告。该方案直接服务 MODE A，风险和收益最平衡。

### 方案 C：完整学习中心

增加早晚完整课程、六触点、听力模式和词形变式。长期价值较高，但
范围过大，会在真实试用前引入大量未经验证的判断。

采用方案 B。

## 4. 角落卡交互设计

### 4.1 尺寸与状态

角落卡有四种主要状态：

1. **收起状态**：约 `58 × 58`，保留当前快速恢复能力。
2. **紧凑提示状态**：约 `360 × 240`。
3. **紧凑答案状态**：仍保持约 `360 × 240`。
4. **详情状态**：在原位置扩展到约 `430 × 386`。

详情关闭后恢复到紧凑状态，不打开第二个窗口，不改变当前显示器和
吸附角落。窗口尺寸变化后重新执行现有的四角吸附计算。

### 4.2 提示状态

默认只显示：

- 当前主题；
- 当天进度；
- 安静默读或开口练习状态；
- 中文或俄语提示；
- 3 秒主动回忆计时；
- “显示答案”；
- 收起和隐藏所需入口。

“下一项”保留在底部次级操作区。朗读、详情和评分在答案揭晓前不
占据主要视觉空间。

### 4.3 答案状态

揭晓后只显示：

- 俄语答案或中文核心义项；
- 一个最常用固定搭配；
- 手动朗读；
- “查看详情”；
- `Again / Hard / Easy`。

评分成功后进入下一项；提交失败时停留在当前项并显示可理解的状态，
不得出现已经前进但数据未保存的情况。

### 4.4 详情状态

详情按内容类型展示：

- 词汇：词性、性别、体和体对、支配关系、第二搭配、例句、关联场景；
- 句子：完整提示、答案、相关词汇和 2–3 轮微型对话。

详情使用滚动区域，不因为俄语长句、字号放大或系统语言造成按钮被
裁切。关闭详情不改变答案揭晓状态。

### 4.5 隐藏与恢复

- `Control + Option + R` 和菜单栏继续切换完全隐藏与显示。
- `Control + Option + C` 继续切换收起与展开。
- 隐藏不清空当天队列，不改变进度，不取消未来提醒。
- 隐藏或切卡时停止朗读并清理临时音频资源。

## 5. AIM Read 视觉语言迁移

### 5.1 颜色

浅色基础令牌：

- 背景与卡片：`#FAF9F5`
- 主文字：`#2A2620`
- 正文：`#3D3929`
- 次要文字：`#83827D`
- 主色：`#C96442`
- 边框：`#DAD9D4`
- 轻强调背景：`#F0EEE7`

深色基础令牌：

- 背景与卡片：`#262624`
- 主文字：`#FAF9F5`
- 正文：`#C3C0B6`
- 次要文字：`#B7B5A9`
- 主色：`#D97757`
- 边框：`#3E3E38`
- 轻强调背景：`#141413`

### 5.2 字体与层级

- 控件和中文使用 macOS 系统字体。
- 俄语答案使用系统衬线设计，不依赖用户额外安装字体。
- 小标签减少全大写和等宽字体使用，只在计时、编号等数据位置保留。
- 主提示、答案、搭配、辅助信息必须形成四级清晰层级。

### 5.3 表面与动效

- 边框保持 1 px 低对比度。
- 阴影改为低半径、低透明度，不制造厚重悬浮感。
- 纸张颗粒降到几乎不可察觉，不影响小字号可读性。
- 展开详情使用短距离淡入和尺寸过渡。
- 系统开启“减少动态效果”时取消位移动画。

### 5.4 可访问性

- 现有字号缩放继续生效。
- 所有图标按钮保留文字辅助标签。
- 主按钮、正文和评分状态满足浅色与深色下的可辨识对比。
- 不能只依赖红、黄、绿颜色区分 `Again / Hard / Easy`。

## 6. 学习机制边界

本轮保留：

- 6 / 10 / 12 自适应新词；
- 每日 5–10 张句子卡；
- 上午俄语到中文识别、下午中文到俄语主动提取；
- `Again / Hard / Easy` 的当前间隔映射；
- 周日只复习已学内容；
- 跨中午和午夜自动刷新；
- 熟练后逐渐使用俄语提示；
- 朗读、诊断和麦克风拒绝后的降级路径。

本轮只记录完成这些任务所需的真实时间，不提前改变卡量。MODE B 再
根据完成率、耗时、正确率和积压决定是否降量或调整任务比例。

## 7. 日常录音功能收敛

### 7.1 问题

第一版日常卡提供录音、停止、播放、保存和丢弃。若应用不提供自动
分析、老师反馈或明确的前后对照任务，这套流程只是重复系统录音机，
要求用户额外回听，和 10–20 秒碎片训练目标冲突。

### 7.2 决策

日常角落卡移除：

- 录音；
- 停止；
- 播放；
- 保存；
- 丢弃。

相关全局录音快捷键从产品说明和注册表中移除，避免留下不可见或无效
入口。已有用户手动保存的录音不删除、不迁移。

### 7.3 周期口述检测

基线诊断和周复测中的录音步骤改为“60 秒口述检测”：

1. 显示场景题目和 3 秒准备倒计时。
2. 用户开始口述，最长 60 秒。
3. 麦克风只读取本地音量包络，用于估算实际开口时长和明显停顿。
4. 不写入音频文件，不提供必须回听的流程。
5. 保存总尝试时长、估算开口时长、明显停顿次数和用户自评。

明显停顿采用本地启发式估算：准备倒计时期间估计环境噪声基线，口述
期间按固定采样窗口判断连续低于阈值的区间。只有持续超过约 1.2 秒的
区间才计为明显停顿。界面必须标注：

> 停顿次数为本机根据音量估算，环境噪声和麦克风距离会影响结果；它
> 不是发音、语法或表达质量评分。

麦克风权限被拒绝时，退化为 60 秒计时和用户自评，诊断仍可完成。

## 8. 7 天试用数据

### 8.1 数据隔离

核心学习进度继续保存在现有 `RussianCorner.store`。试用数据使用独立
的 `RussianCornerTrial.store`，避免为 MODE A 统计修改核心进度数据库
结构。

试用数据库不可用时：

- 正常学习继续工作；
- 进度和调度不受影响；
- 菜单栏显示“试用统计暂时不可用”；
- 不把统计失败伪装成学习提交失败。

### 8.2 会话记录

角落卡可能整天保持可见，因此不能把“显示到隐藏”的墙钟时间当作学习
时长。会话从第一次有效交互开始；连续 3 分钟没有揭晓、朗读、展开、
评分或下一项操作时，在最后一次交互时间结束会话。后续交互创建新
会话。完成、隐藏、退出或跨日也会立即闭合当前会话。

每个试用会话记录：

- 会话 ID；
- 日期；
- 开始和结束时间；
- 完成、隐藏、退出或跨日结束状态；
- 起始与结束队列数量；
- 完成词卡和句子卡数量；
- 新词、复习和剩余积压；
- 中途退出时的卡片种类和队列位置。

报告中的学习时长是这些有效会话时长之和，不包含卡片虽然可见但用户
正在处理其他工作的空闲时间。

### 8.3 交互记录

每次评分额外记录：

- 词卡或句子卡；
- 俄语到中文或中文到俄语方向；
- 中文、俄语或场景提示层级；
- `Again / Hard / Easy`；
- 反应时间；
- 是否展开详情；
- 是否使用朗读；
- 当时练习方式。

试用统计记录失败不能回滚已经成功提交的核心复习事件。

统计口径固定为：

- `Again` 计为本次主动提取未成功；
- `Hard` 和 `Easy` 计为本次主动提取成功；
- 正确率按相同提示方向分别计算，不混合俄语到中文和中文到俄语；
- 中位反应时间只使用已经揭晓并完成评分的记录；
- 展开详情和朗读状态在进入下一项时清零。

### 8.4 每日主观反馈

当天队列完成后最多出现一次，可全部跳过：

1. 今天最卡的地方；
2. 今天有没有一句真正脱口而出；
3. 今天完成或提前退出的原因。

未完成时不弹窗打断工作。用户可从菜单栏主动打开“今日反馈”。反馈
只保存在本地试用数据库。

## 9. Markdown 试用报告

### 9.1 受众

报告首先给用户阅读，而不是给程序阅读。它在 Obsidian、Finder 快速
查看或普通 Markdown 阅读器中应表现为正常中文报告，不要求用户理解
JSON、数据库或统计术语。

同一份 Markdown 也足够供后续 Agent 读取。若需要更细分析，Agent 可
在用户授权后直接读取本地试用数据库，不把机器格式交给用户。

### 9.2 报告内容

导出的 Markdown 包含：

1. 试用日期和实际使用天数；
2. 完成天数、总时长、日均时长；
3. 每日词卡、句卡、新词和复习数量；
4. 三档评分比例；
5. 中文到俄语主动提取的正确率和中位反应时间；
6. 积压变化；
7. 最常退出的环节；
8. 详情和朗读使用情况；
9. 三条主观反馈的逐日记录；
10. 基线与周复测的口述时长和明显停顿估算对比；
11. 明确标注哪些结论是数据、哪些只是用户自评。

报告使用简短表格和自然语言总结，不生成自动学习建议，不在 MODE A
阶段替用户决定下一轮改动。

### 9.3 导出行为

- 用户从菜单栏主动点击“导出 7 天试用报告”。
- 使用系统保存面板选择位置。
- 默认文件名包含起止日期。
- 不自动写入 OneDrive 或 Obsidian。
- 不导出音频、系统路径或无关隐私信息。

## 10. 组件边界

建议新增或调整以下独立单元：

- `CardTheme`：集中管理浅色、深色、字体、边框和阴影令牌。
- `CompactPracticeCard`：提示和答案主路径。
- `PracticeDetailSection`：按需展开的词汇和句子详情。
- `TrialRepository`：独立试用数据库和失败降级。
- `TrialSessionCoordinator`：会话开始、结束和退出原因。
- `DailyReflectionViewModel`：每日三个主观问题。
- `SpeechActivityMonitor`：只产生音量活动指标，不保存音频。
- `TrialReportBuilder`：生成确定性 Markdown。

上述组件不改变 `ReviewScheduler`、内容 JSON 结构、词库 ID 或原始
Obsidian 语料。

## 11. 错误处理

- 核心复习保存成功、试用统计失败：学习继续，显示非阻塞状态。
- 核心复习保存失败：停留当前卡，不写入虚假试用成功记录。
- 报告生成失败：不删除试用数据，可再次导出。
- 保存面板取消：视为用户取消，不显示错误。
- 麦克风拒绝：口述检测退化为计时和自评。
- 系统俄语声音缺失：朗读不可用，但揭晓、评分和统计继续工作。
- 跨午夜：结束旧会话，刷新队列后创建新日期会话。

## 12. 验证计划

### 12.1 自动测试

- 紧凑提示、答案和详情三种视图状态的 ViewModel 测试；
- 详情开关不改变当前项、揭晓状态和评分状态；
- 隐藏和恢复保留队列；
- 核心提交成功但试用统计失败时不回滚学习进度；
- 核心提交失败时不生成试用成功记录；
- 会话在完成、隐藏、退出和跨日时正确闭合；
- 每日反馈一天最多一次且可跳过；
- Markdown 报告在固定样本下输出稳定；
- 报告不包含 JSON、音频路径和内部数据库路径；
- 旧 `RussianCorner.store` 可在新版本继续读取；
- `RussianCornerTrial.store` 损坏或不可写时核心功能可用；
- 麦克风拒绝和无输入时口述检测安全降级；
- 深色和浅色令牌具备必要对比度；
- 原有调度、诊断、提醒、语音和打包测试全部继续通过。

### 12.2 构建与运行

- 严格并发与 warnings-as-errors 测试；
- release 构建；
- bash 和 zsh 打包；
- `Info.plist`、签名、资源哈希和启动烟雾测试；
- 专属核心数据库和试用数据库的打开路径检查；
- 原始 Obsidian 语料哈希复核。

### 12.3 人工验收

- 角落卡在四个角落和不同字号下无裁切；
- 默认卡在工作时的遮挡感明显低于第一版；
- 单次提示、揭晓和评分可在 10–20 秒内完成；
- 深色和浅色均清楚可读；
- 朗读不会自动出声；
- 口述检测在安静和一般背景噪声下给出合理但明确标注为估算的结果；
- Markdown 报告在 Obsidian 中可直接阅读。

## 13. 完成条件

MODE A 优化完成必须同时满足：

1. 默认卡面已经收敛到碎片主动提取主路径。
2. AIM Read 视觉令牌以 macOS 原生方式实现。
3. 日常录音机式功能已从主路径移除。
4. 周期口述检测无需用户回听即可产生有限、诚实的估算指标。
5. 7 天试用数据和每日反馈可完全本地保存。
6. 用户可导出一份正常可读的中文 Markdown 报告。
7. 旧进度、调度、权限降级和隐藏恢复没有回归。
8. 自动测试、构建、签名、启动和原始语料哈希验证通过。
9. 完成后停止继续加功能，交付 7 天试用版本并等待真实反馈。
