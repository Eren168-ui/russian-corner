# 俄语角落卡｜HTML 产品落地页与长图海报设计 Prompt

请你担任资深产品设计师、品牌视觉设计师和前端开发者，为 macOS 应用「俄语角落卡」设计一份高完成度的 HTML 产品落地页。最终成果不是传统企业官网，而是一张可以连续阅读、可以完整导出为超长 PNG、也可以按章节导出为多张独立海报的“产品故事长图”。

请直接完成设计和 HTML 实现，不要只给线框图、设计说明或文字方案。

## 一、产品背景

产品名称：俄语角落卡  
俄语名称：РУССКИЙ УГОЛОК  
产品形态：macOS 菜单栏应用 + 常驻桌面的轻量学习卡片  
核心用户：已有 A2 左右基础、语法不差，但词汇量不足、开口时容易先想中文、认识单词却不能迅速主动调用的俄语学习者。

这不是传统背单词软件。产品的重点是让用户在每天工作的碎片时间里，通过场景表达、主动回忆、词汇解析和间隔复习，持续接触并开口说俄语。

核心学习链路：

`场景意图 → 主动说俄语 → 揭晓自然表达 → 点击任意单词 → 查看词义与用法 → 复习并再次输出`

真实功能与数据：

- 32 个日常交流主题。
- 214 张经过内容审核的长期场景句卡。
- 360 个本地俄语词条。
- 句子里的每一个俄语单词都可以点击。
- 点击后可查看重音、原形、当前词形、中文义、词性、动词体、支配关系、搭配和场景例句。
- 本地资料不足时，可以使用在线词典补充查询。
- 每日内容自动轮换，也可以手动选择当天话题。
- 根据复习积压和主动回忆正确率，自动调整每日新词数量。
- 支持俄语朗读、主动回忆计时和开口活动统计。
- 默认不保存录音，不假装自动判断发音是否地道。
- 卡片可以自由拖到桌面任意位置并记住位置；也可以主动选择四角吸附。
- 支持隐藏、折叠、置顶、透明度、字号、快捷键和多显示器。
- 学习进度保存在本地，提供话题覆盖、连续学习、正确率、掌握量和近 7 天学习报告。
- 原始学习笔记只读；新增内容先进入隔离候选区，未经审核不会直接投放。

不得虚构以下功能：

- 不要写 AI 实时陪练、AI 自动纠正发音、母语者一对一点评。
- 不要写云同步、跨设备同步、账号体系或手机端。
- 不要伪造用户数量、学习效果百分比、媒体奖项、用户评价、价格或上线日期。

## 二、落地页目标

让访问者在 20 秒内明白：

1. 它解决的是“认识俄语但说不出来”，不是单纯记忆孤立单词。
2. 它把句子、单词、搭配和真实对话场景连接在一起。
3. 它不会打断工作，而是安静地待在桌面上，随时练两句。
4. 它是一套适合长期使用的本地学习系统，不是 7 天试用 Demo。

希望画面产生的感受：

- 克制、聪明、安静、有语言学习的文化气质。
- 像一本经过精心编排的现代语言杂志，而不是廉价教育广告。
- 信息密度较高，但层级非常清楚。
- 具有 macOS 产品的精致感，同时保留纸张、批注和语言卡片的触感。

## 三、视觉方向

参考现代编辑设计、瑞士国际主义版式、独立杂志和高质量数字阅读产品。可以吸收 aim-read.top 一类产品的内容层级、留白和阅读节奏，但不要复制其页面、插画或具体组件。

推荐视觉母版：

- 主背景：温暖的米白或浅纸色，避免纯白刺眼。
- 主文字：墨黑或深蓝黑。
- 强调色：低饱和砖红、陶土橙或克制的俄式红，只用于交互词、数字和关键节点。
- 辅助色：灰蓝、鼠尾草绿、淡沙色。
- 字体气质：中文使用现代宋体与无衬线字体组合；俄语标题可使用优雅衬线体；数据和标签使用等宽字体。
- 使用细线、编号、页码、重音符号、词典索引、卡片层叠、轻微纸张纹理形成识别度。
- 不要大面积玻璃拟态、霓虹渐变、赛博朋克、卡通吉祥物、廉价 3D 图标或夸张营销光效。
- 动效只服务于网页演示；导出静态图片时所有信息必须完整可见。

## 四、长图内容结构

页面宽度以桌面产品展示为主，建议设计基准宽度 1440px。完整长图建议约 9000–12000px 高，根据内容自然延伸。每个章节必须有独立 `data-export-section`，能够单独导出为 1440px 宽的 PNG。

### 01｜Hero：你不是不会俄语，只是还没练到脱口而出

主标题必须逐字出现：

「把俄语放在桌面一角，每天真正说几句。」

辅助标题：

「俄语角落卡是一款为 A2→B1 阶段设计的 macOS 主动口语学习工具。」

展示一张最有吸引力的桌面场景：真实感的 macOS 桌面局部，角落卡悬浮其中。卡片里出现一句带重音的俄语表达，正文中的单词具有可点击的视觉状态。

首屏不要堆全部功能。只保留产品名、核心价值、一个产品主视觉和简短行动文案：

「不是再背一遍，而是把认识的俄语变成说得出口的俄语。」

### 02｜问题：为什么语法分数不低，开口还是会卡住

用四个清晰的问题模块呈现：

- 认识的词多，会主动使用的词少。
- 单词、搭配和句子彼此割裂。
- 开口时先想中文，再临时翻译。
- 一边说，一边检查词形和语法，反应自然变慢。

核心文案：

「卡住你的，往往不是语法知识，而是词汇与句块没有形成自动调用。」

这一屏可以使用中文思考气泡逐渐转换为俄语表达的图形叙事，但不要做成幼稚流程图。

### 03｜核心体验：从一句真实表达进入词汇世界

以一张大型交互句卡为视觉中心：

中文意图：

「我想确认一下预订是否成功。」

俄语表达：

「Я хочу́ уточни́ть, прошла́ ли бронь.»

把句中的 `уточни́ть` 和 `бронь` 设计成明显可点击状态，并展开其中一个词的解析面板，展示：

- 重音与发音
- 中文核心义
- 原形与当前词形
- 词性与必要语法
- 常见支配关系
- 固定搭配
- 场景例句

核心文案：

「句子始终是主角。词义和语法，只在你需要时展开。」

### 04｜学习链路：不是“看懂”，而是主动把话说出来

以连续但克制的五步叙事呈现：

1. 看到中文意图或俄语场景。
2. 在 3–5 秒内主动说出俄语。
3. 揭晓自然表达并听朗读。
4. 点击不认识的词，理解搭配和用法。
5. 选择“不会 / 想起来了 / 脱口而出”，进入下一次复习。

突出“先回忆，再揭晓”，不要把页面做成普通功能列表。

### 05｜每天只占一点空间，却能持续发生

展示卡片处于桌面不同位置的几个状态：

- 工作时安静停在任意位置。
- 自由拖放并记住位置。
- 主动选择四角吸附。
- 一键折叠为小方块。
- 一键隐藏，需要时再次唤出。

准确文案：

「它不会催你完成一堂课，只是在你有空的几十秒里，递来一句值得说出口的俄语。」

避免把同一张卡机械复制四次。使用桌面空间、窗口遮挡和位置变化讲清楚“不打扰”。

### 06｜长期内容系统：今天练什么，不需要每天重新决定

用内容地图或编辑式索引展示 32 个生活主题中的代表性类别：

- 电话与联络
- 问路与交通
- 餐厅与购物
- 医院与身体不适
- 住宿与租房
- 学校与大学生活
- 家庭、邀请与社交
- 旅行与城市交流

突出数据：

- `32` 个日常主题
- `214` 张审核场景句卡
- `360` 个本地词条
- `100%` 句中俄语词可点击

这里的 `100%` 仅指可点击覆盖，不得解释为学习效果或词典释义完整率。

核心文案：

「每天自动轮换，也允许你手动决定今天想练哪个场景。」

### 07｜复习不是固定任务，而是跟着你的状态变化

用简洁的数据叙事表现：

- 回忆正确率较低或复习积压时，减少新词。
- 状态稳定时维持节奏。
- 连续表现良好时适度增加。
- 熟练后逐步减少中文提示，转为俄语提示。

展示 `1 / 3 / 7 / 14 / 30 天` 的递增复习节奏。

不要使用“AI 为你精准规划”等夸张说法。文案使用“本地自适应调度”。

### 08｜本地、克制、可追溯

用一屏建立可信感：

- 学习进度保存在本地。
- 默认不保存录音。
- 没有俄语系统声音或拒绝麦克风权限时，核心学习仍然可用。
- 原始 Obsidian 笔记保持只读。
- 新增内容必须经过审核后才能进入训练。
- 在线词典只用于按需补充单词信息。

核心文案：

「学习资料可以不断增长，但未经审核的内容不会悄悄混进你的每日练习。」

### 09｜进度与收束

展示学习进度面板：

- 今日完成
- 连续学习
- 今日正确率
- 已掌握
- 话题覆盖
- 近 7 天学习报告

结尾主标题：

「真正的目标，不是多认识几个词，而是下一次需要时能直接说出来。」

结尾行动文案：

「打开俄语角落卡，从今天的一句话开始。」

不要虚构下载地址。可以设计一个克制的 CTA 视觉按钮，但按钮文字只写：

「开始每天说几句俄语」
