# 俄语角落卡｜macOS 应用图标生成 Prompt

## 1. 需求理解

- 场景：macOS 原生应用图标，同时用于 Finder、Dock、菜单栏应用列表和安装包展示。
- 核心目标：让人一眼感受到“桌面角落卡片、俄语口语、碎片化学习”，但不做成传统背单词软件或俄罗斯国旗图标。
- 目标受众：已有俄语基础、希望通过日常场景表达提高开口能力的学习者。
- 视觉方向：克制、现代、编辑设计感，具有清晰的小尺寸识别度。

## 2. 已补全的设计判断

- 采用“悬浮卡片折角 + 对话声波 + 重音符号”的组合，比直接使用俄文字母更像一个成熟产品。
- 使用墨蓝、暖米白和低饱和珊瑚橙，延续应用界面的深色、阅读型气质。
- 不使用国旗、套娃、圣瓦西里教堂等俄罗斯刻板符号。
- 不生成文字，避免模型生成错误俄文字母，也确保缩小后清楚。

## 3. 参考图使用说明

当前按纯文本生成，不依赖参考图。图标生成后请保留未经压缩的 1024 × 1024 原图，不要自行裁成圆形。

## 5. 出图验收重点

- 缩小到 32 × 32 px 后仍能看清“卡片折角”。
- 图形只有一个视觉中心，没有多个零散符号。
- 没有文字、错误俄文字母、国旗或俄罗斯刻板元素。
- 颜色与应用现有深色界面协调，但在 Dock 中不会糊成一块黑色。
- 四周留白充分，转换为 `.icns` 后不会被 macOS 圆角裁切。
